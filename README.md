# Pelajaran Dasar Python

Kumpulan contoh program sederhana untuk mempelajari dasar-dasar pemrograman Python secara bertahap dan praktis.

## Materi yang Dipelajari

- Menampilkan teks dan menerima input pengguna
- Variabel dan tipe data
- Operator serta perhitungan sederhana
- Percabangan `if`, `elif`, dan `else`
- Perulangan `for` dan `while`
- Penggunaan `break`, `continue`, dan `for-else`
- List atau array
- Fungsi
- Algoritma pencarian sederhana
- File handling
- Dasar-dasar Object-Oriented Programming (OOP)

## Struktur File

| File/Folder | Materi |
| --- | --- |
| `Hello.py` | Program pertama: menampilkan teks |
| `Variabel.py` | Variabel, nilai, dan perhitungan sederhana |
| `Tipe_data.py` | Integer, float, string, boolean, dan tipe data lainnya |
| `Input.py` | Menerima masukan dari pengguna |
| `If_else.py` | Percabangan kondisi |
| `For_string.py` | Perulangan pada string |
| `Perulangan.py` | Perulangan menggunakan `range()` |
| `For_else.py` | Pencarian data dengan `for-else` |
| `While_loop.y.py` | Perulangan `while` dan validasi password |
| `While_else.py` | Batas percobaan menggunakan `while-else` |
| `Break.py` | Menghentikan perulangan dengan `break` |
| `Continue.py` | Melewati iterasi dengan `continue` |
| `Array.py` | Menambah, mengubah, dan menghapus data pada list |
| `Function.py` | Membuat dan menggunakan fungsi |
| `Data_dan_algoritma.py` | Algoritma linear search |
| `Handling/Handling.py` | Membuat, membaca, menambah, dan menghapus file |
| `OOP/` | Contoh penerapan konsep OOP dalam beberapa kasus |

## Cara Menjalankan

Pastikan Python 3 sudah terpasang, kemudian buka terminal pada folder proyek dan jalankan salah satu file berikut:

```bash
python Hello.py
```

Contoh lain:

```bash
python While_loop.y.py
python Handling/Handling.py
python OOP/sekolah.py
```

Beberapa program meminta input dari pengguna. Ikuti instruksi yang muncul pada terminal.
